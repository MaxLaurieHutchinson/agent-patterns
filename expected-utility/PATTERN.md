# Expected Utility (Plain Language)

## What It Is
Computes expected utility over outcomes and selects max.

## When To Use
- When you need choose option with highest expected value.

## When Not To Use
- When you need a different decision model

## Inputs
- options with outcomes

## Outputs
- best option

## Workflow
1. Compute expected utility
2. Choose max

## Minimal Example
Pick strategy under uncertain demand.

## Evaluation Checklist
- [ ] Produces expected output
- [ ] Handles invalid input safely
- [ ] Is deterministic where expected

## Common Pitfalls
- Using unnormalized probabilities
- Mixing incomparable utility scales
- Ignoring risk preferences
