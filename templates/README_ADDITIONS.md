# README Additions Guidance

Use this checklist when authoring a pattern README:

1. Keep a short conceptual explanation at top.
2. Include explicit tradeoffs and non-goals.
3. Include security/safety notes if side effects exist.
4. Link to:
- `PATTERN.md` for plain-language explanation
- `AGENT_SPEC.md` for machine-oriented execution steps
5. Keep examples runnable with clear prerequisites.
